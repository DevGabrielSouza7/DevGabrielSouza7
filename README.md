## 👨‍💻 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas** na Uninassau, com foco na construção de aplicações web e mobile — desde a estrutura de banco de dados até interfaces interativas. Gosto de desenvolver soluções que tenham utilidade no mundo real.

- 🎓 Cursando Ensino Superior em Análise e Desenvolvimento de Sistemas.
- 🚀 Experiência prática criando apps e sistemas com **Java**, **Flutter**, **React Native** e **Node.js**.
- 💡 Buscando sempre aprender novas tecnologias, padrões de arquitetura e código limpo.
- 🎮 Quando não estou programando, provavelmente estou jogando algo (Elden Ring, God of War), assistindo a algum anime, cuidando do meu Husky ou fazendo upgrades no meu setup.
